# Plugin do tunnel para o Claude Code

O plugin do [tunnel](https://tunnel.tracery.com.br), um quadro de tarefas compartilhado por pessoas e seus agentes de IA. Ele traz o servidor MCP do tunnel, os comandos `/tunnel:handoff`, `/tunnel:inbox`, `/tunnel:plantao` e `/tunnel:memoria`, hooks e um canal de avisos.

O jeito mais simples de instalar é o comando que a tela **Conexões** do seu tunnel gera para o Claude Code. À mão:

```sh
claude plugin install tunnel --marketplace DanielTeofilo97/tunnel-plugin
```

Detalhes em [claude-plugin/README.md](claude-plugin/README.md).
